【第 6/6 步：编译并运行到手机上 flutter run】

这一步在干什么：
  把 Dart 代码编译成手机能执行的东西，装到你的手机上，然后启动。

第一次会特别慢（3-10 分钟）！
  因为要下载 Android 编译工具（Gradle 相关的组件），
  几百 MB 起步，属正常现象，请不要中途关窗口。

怎么操作：
  1. 用数据线连上手机，并在手机上打开「开发者选项 → USB 调试」。
     （设置 → 关于手机 → 连续点 7 次「版本号」可打开开发者选项）
  2. 手机上如果弹出「是否允许调试」的框，点「允许」。
  3. 看着窗口，等它出现 "Syncing files to device ..." 和一个调试菜单。

启动成功后你会看到：
  App 会自动打开，进入相册授权页面，点「允许」就能进首页。
  此时这个窗口不要关——关掉了 App 就断了。
  在这个窗口里按键盘 r = 热重载（改代码后秒生效，不用重新编译）
                     R = 彻底重启 App
                     q = 退出（App 会留在手机上，能正常使用）

如果失败：
  最常见三种原因：
  * 手机没连上 / USB 调试没开 / 没点「允许调试」
  * 编译时下载 Gradle 组件失败 → 检查 Clash 代理端口
  * 代码有编译错误 → 看错误信息里的文件名和行号

退出方式：
  回到这个黑色窗口按 q，或者直接关窗口。
  App 已经装在手机上了，关掉窗口不影响继续使用。
